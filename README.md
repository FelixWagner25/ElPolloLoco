# El Pollo Loco - Jump and Run Game

El Pollo Loco is a browser-based two-dimensional jump and run game build with plain JavaScript, focusing on object oriented programming.<br>
The project was developed as part of the Developer Akademie Frontend Course.

## Content

- Two-dimensional browser-based jump and run game.

## Tech Stack

- JavaScript - Game logic, animations
- HTML - Canvas rendering and structure
- CSS - Styling and layout

## Local Installation

```bash
git clone https://github.com/FelixWagner25/ElPolloLoco.git
```

Open `index.html` in your browser
